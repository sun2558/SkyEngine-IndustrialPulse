# SkyEngine-IndustrialPulse
# 天擎：工业脉冲引擎

将领域知识代码化的混合智能系统，把专家经验变成可执行的规则，与数据模型融合，适配工业命题。

## 核心模块

- **规则插拔框架** - 动态加载/卸载工业规则，三西格玛与IQR自动切换
- **MySQL模块** - 工业数据持久化存储（raw_data、cleaned_data、rules、explanations、reports）
- **爬虫模块** - 多领域数据采集（气象/电商/工业），支持CSV及网关API
- **可视化模块** - Vue + ECharts 实时监控大屏，异常点标红，原因列表展示
- **可解释AI接口** - 将异常检测结果翻译为人话，存入explanations表

## 技术栈
- **后端**：Python + Flask + MySQL + PyMySQL
- **前端**：Vue 3 + ECharts + Axios
- **算法**：NumPy + SciPy（偏度计算、IQR、3σ）
- **部署**：工业网关（MBox20）+ 本地化运行
